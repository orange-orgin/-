# 校园线上点餐学生端Demo

基于微信原生小程序（WXML+WXSS+JS）开发的校园点餐系统学生端Demo。

## 功能清单

### 核心功能
- **微信一键授权登录** - 支持微信授权登录和游客模式
- **首页商家分类** - 6大商家分类展示
- **轮播公告** - 首页顶部公告轮播
- **菜品搜索** - 支持模糊搜索匹配
- **商家详情** - 商家信息+菜品列表
- **菜品详情** - 商品信息+用户评价
- **购物车** - 同商家校验、增减数量、清空
- **订单结算** - 对接微信支付模拟
- **订单状态** - 待接单/制作中/已完成/已取消
- **取餐码展示** - 下单后显示取餐码
- **订单图文评价** - 支持评分+标签+文字评价
- **个人中心** - 用户信息+订单统计

### 交互规则
- 加入购物车**抛物线动画**
- 购物车角标实时更新
- 下单前校验**菜品库存**和**商家营业状态**
- 异常处理：无数据空页面、网络错误提示、重复下单拦截

## 使用说明

### 1. 导入项目
1. 下载完整项目代码
2. 打开微信开发者工具
3. 选择"导入项目"
4. 选择本项目目录
5. AppID处填写您的小程序AppID（可先使用测试号）

### 2. 添加TabBar图标
在 `images/` 目录下添加以下图标文件（建议尺寸 81x81）：
- `home.png` / `home-active.png` - 首页图标
- `order.png` / `order-active.png` - 订单图标  
- `mine.png` / `mine-active.png` - 我的图标

或修改 `app.json` 中的 `tabBar.list` 配置使用自定义路径。

### 3. 运行项目
1. 点击"编译"按钮
2. 在模拟器中查看效果
3. 可使用"预览"生成二维码在真机测试

## 数据说明

本项目所有数据均为本地Mock模拟：
- 商家数据：`utils/mockData.js`
- API接口：`utils/api.js`

如需对接真实后端，修改 `utils/api.js` 中的接口函数。

## 技术栈

- WXML - 微信小程序模板
- WXSS - 微信小程序样式
- JavaScript - 原生JS（ES6+）
- 本地存储 - wx.setStorageSync / wx.getStorageSync

## 注意事项

1. **登录验证**：除登录页外，其他页面需登录后可访问
2. **购物车规则**：只允许同一商家商品，切换商家会提示清空
3. **订单限制**：5分钟内同一商家不可重复下单
4. **支付模拟**：支付成功率95%，失败会提示重试
